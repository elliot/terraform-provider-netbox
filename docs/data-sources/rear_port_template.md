# netbox_rear_port_template (Data Source)

Reads a single NetBox rear port template (`/api/dcim/rear-port-templates/`) by `id`, `name` or filters.

## Example Usage

```terraform
data "netbox_device_type" "pp" {
  slug = "pp-24-lc"
}
data "netbox_rear_port_template" "example" {
  filters = [
    { name = "device_type_id", value = data.netbox_device_type.pp.id },
    { name = "name", value = "Trunk 1" },
  ]
}
```

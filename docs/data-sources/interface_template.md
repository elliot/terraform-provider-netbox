# netbox_interface_template (Data Source)

Reads a single NetBox interface template (`/api/dcim/interface-templates/`) by `id`, `name` or filters.

## Example Usage

```terraform
data "netbox_device_type" "c9300" {
  slug = "c9300-48p"
}
data "netbox_interface_template" "example" {
  filters = [
    { name = "device_type_id", value = data.netbox_device_type.c9300.id },
    { name = "name", value = "GigabitEthernet0/0" },
  ]
}
```

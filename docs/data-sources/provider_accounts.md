# netbox_provider_accounts (Data Source)

Lists NetBox provider account objects (`/api/circuits/provider-accounts/`) matching the given filters.

## Example Usage

```terraform
data "netbox_provider_accounts" "lumen" {
  filters = [
    { name = "provider", value = "lumen" },
  ]
}

output "lumen_accounts" {
  value = data.netbox_provider_accounts.lumen.items[*].account
}
```

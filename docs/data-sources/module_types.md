# netbox_module_types (Data Source)

Lists NetBox module type objects (`/api/dcim/module-types/`) matching the given filters.

## Example Usage

```terraform
# Every module type of one parent object.
data "netbox_module_types" "all" {
  filters = [
    { name = "manufacturer", value = "cisco" },
  ]
}
output "module_types_names" {
  value = data.netbox_module_types.all.items[*].model
}
```

# netbox_console_server_port_template (Data Source)

Reads a single NetBox console server port template (`/api/dcim/console-server-port-templates/`) by `id`, `name` or filters.

## Example Usage

```terraform
data "netbox_device_type" "om2248" {
  slug = "om2248"
}
data "netbox_console_server_port_template" "example" {
  filters = [
    { name = "device_type_id", value = data.netbox_device_type.om2248.id },
    { name = "name", value = "port1" },
  ]
}
```

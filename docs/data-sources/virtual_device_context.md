# netbox_virtual_device_context (Data Source)

Reads a single NetBox virtual device context (`/api/dcim/virtual-device-contexts/`) by `id`, `name` or filters.

## Example Usage

```terraform
data "netbox_device" "sw01" {
  name = "dc1-access-sw01"
}
data "netbox_virtual_device_context" "example" {
  filters = [
    { name = "device_id", value = data.netbox_device.sw01.id },
    { name = "name", value = "cust-a-vdc" },
  ]
}
```

# netbox_config_template (Data Source)

Reads a single NetBox config template (`/api/extras/config-templates/`) by `id`, `name` or filters.

## Example Usage

```terraform
data "netbox_config_template" "base" {
  name = "base-config"
}

resource "netbox_platform" "ios" {
  name               = "Cisco IOS"
  slug               = "cisco-ios"
  config_template_id = data.netbox_config_template.base.id
}
```

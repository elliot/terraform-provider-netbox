# netbox_data_sources (Data Source)

Lists NetBox data source objects (`/api/core/data-sources/`) matching the given filters.

## Example Usage

```terraform
data "netbox_data_sources" "all" {}

data "netbox_data_sources" "filtered" {
  filters = [
    { name = "type", value = "git" },
  ]
  limit = 50
}

output "data_sources_ids" {
  value = data.netbox_data_sources.filtered.items[*].id
}
```

# netbox_wireless_lans (Data Source)

Lists NetBox wireless lan objects (`/api/wireless/wireless-lans/`) matching the given filters.

## Example Usage

```terraform
data "netbox_wireless_lans" "campus" {
  filters = [
    { name = "group", value = "campus" },
    { name = "status", value = "active" },
  ]
}

output "campus_ssids" {
  value = data.netbox_wireless_lans.campus.items[*].ssid
}
```

# netbox_config_context_profile (Data Source)

Reads a single NetBox config context profile (`/api/extras/config-context-profiles/`) by `id`, `name` or filters.

## Example Usage

```terraform
data "netbox_config_context_profile" "ntp" {
  name = "ntp"
}

resource "netbox_config_context" "ntp_apac" {
  name       = "ntp-apac"
  profile_id = data.netbox_config_context_profile.ntp.id
  data       = jsonencode({ ntp_servers = ["10.20.0.1"] })
}
```

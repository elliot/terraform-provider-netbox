# netbox_inventory_item_template (Data Source)

Reads a single NetBox inventory item template (`/api/dcim/inventory-item-templates/`) by `id`, `name` or filters.

## Example Usage

```terraform
data "netbox_device_type" "c9300" {
  slug = "c9300-48p"
}
data "netbox_inventory_item_template" "example" {
  filters = [
    { name = "device_type_id", value = data.netbox_device_type.c9300.id },
    { name = "name", value = "PSU 1" },
  ]
}
```

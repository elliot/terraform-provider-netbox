# netbox_module_bay_template (Data Source)

Reads a single NetBox module bay template (`/api/dcim/module-bay-templates/`) by `id`, `name` or filters.

## Example Usage

```terraform
data "netbox_device_type" "c9300" {
  slug = "c9300-48p"
}
data "netbox_module_bay_template" "example" {
  filters = [
    { name = "device_type_id", value = data.netbox_device_type.c9300.id },
    { name = "name", value = "Network Module 1" },
  ]
}
```

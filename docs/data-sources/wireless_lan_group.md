# netbox_wireless_lan_group (Data Source)

Reads a single NetBox wireless lan group (`/api/wireless/wireless-lan-groups/`) by `id`, `name`, `slug` or filters.

## Example Usage

```terraform
data "netbox_wireless_lan_group" "campus" {
  slug = "campus"
}

resource "netbox_wireless_lan" "corp" {
  ssid     = "Corp-WiFi"
  group_id = data.netbox_wireless_lan_group.campus.id
}
```

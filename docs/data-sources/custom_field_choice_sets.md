# netbox_custom_field_choice_sets (Data Source)

Lists NetBox custom field choice set objects (`/api/extras/custom-field-choice-sets/`) matching the given filters.

## Example Usage

```terraform
data "netbox_custom_field_choice_sets" "iso" {
  filters = [{ name = "base_choices", value = "ISO_3166" }]
}

output "iso_choice_sets" {
  value = data.netbox_custom_field_choice_sets.iso.items[*].name
}
```

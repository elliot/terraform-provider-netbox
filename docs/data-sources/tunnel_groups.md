# netbox_tunnel_groups (Data Source)

Lists NetBox tunnel group objects (`/api/vpn/tunnel-groups/`) matching the given filters.

## Example Usage

```terraform
data "netbox_tunnel_groups" "all" {}

data "netbox_tunnel_groups" "filtered" {
  filters = [
    { name = "q", value = "branch" },
  ]
  limit = 50
}

output "tunnel_group_slugs" {
  value = data.netbox_tunnel_groups.filtered.items[*].slug
}
```

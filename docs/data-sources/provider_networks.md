# netbox_provider_networks (Data Source)

Lists NetBox provider network objects (`/api/circuits/provider-networks/`) matching the given filters.

## Example Usage

```terraform
data "netbox_provider_networks" "lumen" {
  filters = [
    { name = "provider", value = "lumen" },
  ]
}

output "lumen_network_names" {
  value = data.netbox_provider_networks.lumen.items[*].name
}
```

# netbox_power_port_template (Data Source)

Reads a single NetBox power port template (`/api/dcim/power-port-templates/`) by `id`, `name` or filters.

## Example Usage

```terraform
# Template names are unique per device type (or module type).
data "netbox_device_type" "sw48" {
  slug = "example-sw-48"
}

data "netbox_power_port_template" "example" {
  filters = [
    { name = "device_type_id", value = data.netbox_device_type.sw48.id },
    { name = "name", value = "PSU1" },
  ]
}
```

# netbox_custom_field_choice_set (Resource)

Manages a NetBox custom field choice set (`/api/extras/custom-field-choice-sets/`).

## Example Usage

```terraform
# Each choice is a [value, label] pair.
resource "netbox_custom_field_choice_set" "support_tier" {
  name        = "Support tier"
  description = "Vendor support contract level"
  extra_choices = [
    ["bronze", "Bronze"],
    ["silver", "Silver"],
    ["gold", "Gold"],
  ]
  # Colour names, not hex codes: blue, indigo, purple, pink, red, orange,
  # yellow, green, teal, cyan, gray, black, white.
  choice_colors = jsonencode({
    bronze = "orange"
    silver = "gray"
    gold   = "yellow"
  })
}

# Extend one of NetBox's built-in choice lists. With order_alphabetically the
# API returns extra_choices sorted, so keep the configured list sorted too.
resource "netbox_custom_field_choice_set" "countries" {
  name         = "Countries"
  base_choices = "ISO_3166"
  extra_choices = [
    ["XK", "Kosovo"],
  ]
  order_alphabetically = true
}
```

## Schema

### Required

- `extra_choices` (List of List of String) Extra Choices.
- `name` (String) Name.

### Optional

- `base_choices` (String) Base set of predefined choices (optional). Valid values: `IATA`, `ISO_3166`, `UN_LOCODE`. Defaults to the NetBox server default when omitted.
- `choice_colors` (String) Colors per choice value as a JSON object (`jsonencode({ gold = "yellow" })`). Values are NetBox colour names: `blue`, `indigo`, `purple`, `pink`, `red`, `orange`, `yellow`, `green`, `teal`, `cyan`, `gray`, `black`, `white` (not hex codes).
- `description` (String) Description. Defaults to an empty string.
- `order_alphabetically` (Boolean) Choices are automatically ordered alphabetically. Defaults to the NetBox server default when omitted.
- `owner_id` (Number) ID of the Owner (`netbox_owner`).

### Read-Only

- `created` (String) Created.
- `id` (Number) The numeric ID of the object in NetBox.
- `url` (String) Url.

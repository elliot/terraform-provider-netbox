# netbox_cluster_type (Resource)

Manages a NetBox cluster type (`/api/virtualization/cluster-types/`).

## Example Usage

```terraform

  name        = "VMware vSphere"
  slug        = "vmware-vsphere"
  description = "vSphere 8 clusters"
}

resource "netbox_cluster_type" "proxmox" {
  name = "Proxmox VE"
  slug = "proxmox-ve"
}
```

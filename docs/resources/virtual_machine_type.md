# netbox_virtual_machine_type (Resource)

Manages a NetBox virtual machine type (`/api/virtualization/virtual-machine-types/`).

## Example Usage

```terraform

resource "netbox_virtual_machine_type" "m_large" {
  name        = "m.large"
  slug        = "m-large"
  description = "2 vCPU, 8 GB RAM, general purpose"
```

# netbox_provider (Resource)

Manages a NetBox Manages a NetBox circuit provider (`/api/circuits/providers/`): a carrier or service provider that delivers circuits. Accounts are managed with `netbox_provider_account` (`/api/circuits/providers/`).

## Example Usage

```terraform
resource "netbox_provider" "example" {
  name        = "Lumen"
  slug        = "lumen"
  description = "Long-haul transport and DIA provider"
  comments    = "NOC: +1 877 453 8353"
}
```

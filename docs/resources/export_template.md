# netbox_export_template (Resource)

Manages a NetBox export template (`/api/extras/export-templates/`).

## Example Usage

```terraform
# Export sites as CSV. `queryset` holds the objects selected in the UI.
resource "netbox_export_template" "sites_csv" {
  name           = "sites-csv"
  description    = "Site inventory for the facilities team"
  object_types   = ["dcim.site"]
  mime_type      = "text/csv"
  file_name      = "sites"
  file_extension = "csv"
  as_attachment  = true
  # NetBox strips surrounding whitespace from text fields: trim the heredoc.
  template_code = trimspace(<<-EOT
    name,status,region,facility
    {% for site in queryset %}{{ site.name }},{{ site.status }},{{ site.region }},{{ site.facility }}
    {% endfor %}
  EOT
  )
}
```

### Optional

- `as_attachment` (Boolean) Download file as attachment. Defaults to the NetBox server default when omitted.
- `data_source_id` (Number) ID of the Data Source (`netbox_data_source`).
- `description` (String) Description. Defaults to an empty string.
- `environment_params` (String) Any <a href="https://jinja.palletsprojects.com/en/stable/api/#jinja2.Environment">additional parameters</a> to pass when constructing the Jinja environment.
- `file_extension` (String) Extension to append to the rendered filename. Defaults to an empty string.
- `file_name` (String) Filename to give to the rendered export file. Defaults to an empty string.
- `mime_type` (String) Defaults to <code>text/plain; charset=utf-8</code>. Defaults to an empty string.
- `owner_id` (Number) ID of the Owner (`netbox_owner`).

### Read-Only

- `created` (String) Created.
- `id` (Number) The numeric ID of the object in NetBox.
- `url` (String) Url.
